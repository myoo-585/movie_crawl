# 电影爬取

---

## 猫眼电影爬虫

基于scrapy 、mysql 的猫眼爬虫项目。本项目重点解决了**字体反爬及signKey破解**的问题，爬取了正在热映电影的相关数据。

### 项目亮点：

- **数据清洗入库**： 使用相关的xpath、re来清洗数据，清洗好的数据放入数据库

- **字体解密**：解析网页找到并拼接.woff的url，下载使用，转换成ttf，建立映射关系从而破解

- **逆向js**：分析并破解signKey，成功爬取各个电影的具体页面

### 技术栈：

- **爬虫框架**： scrapy

- **数据存储**：mysql

- **字体处理**：fontTools（用于解析woff字体）

- **数据提取**：xpath， re

### 已实现内容（多页爬取）:

| *字段*       | *说明*                         | *备注*                   |
| ------------ | ------------------------------ | ------------------------ |
| **电影名称** | 影片全称                       |                          |
| **核心数据** | 评分、票房                     | 字体加密已破解           |
| **演职人员** | 导演、演员                     | 共爬取5人（导演 + 演员） |
| **详情信息** | 类型、国家、上映时间、电影时长 |                          |
| **剧情简介** | 简介                           |                          |

### 注意事项：

若数据库里的star和box_office类型不对，在mysql试试这个：

> "ALTER TABLE maoyan_movie ADD COLUMN box_office VARCHAR(50) COMMENT 'box_office'"

- 数据库的密码可以放在.env.example里
